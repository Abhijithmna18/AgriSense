## 🚀 Quick Start

### Backend
```bash
cd mini-banking-system/backend
npm install
cp .env.example .env
# Add your MongoDB Atlas URI to .env
npm run dev
```

### Frontend
```bash
cd mini-banking-system/frontend
npm install
npm run dev
```

**Server runs on**: http://localhost:5000
**Frontend runs on**: http://localhost:3000

## 🔧 Environment Setup

Create `.env` file in backend:
```env
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/minibank
JWT_SECRET=your_super_secret_key_here
PORT=5000
FD_INTEREST_RATE=7.5
DAILY_TRANSACTION_LIMIT=100000
SINGLE_TRANSACTION_LIMIT=50000
```
